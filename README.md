# Altaigame Box (h5gaming3)

English-only mobile H5 game box for `h5gaming3.altaimobile.com`.

- Static site: `index.html`, `css/`, `js/`, `games.json`
- ~100 MIT open-source H5 games with matching icons
- Ad slots left empty for inventory
- Visual theme: violet / amber accents with Staff Picks (differentiated from h5gaming1 and h5gaming2)

Deployed via GitHub Pages + Cloudflare DNS-only CNAME to `jh0n-sn0w.github.io`.
